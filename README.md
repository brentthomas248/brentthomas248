# Brent Showalter

I build software around real business workflows: useful interfaces, data pipelines and tests that make failures easier to find.

My work spans Python, TypeScript and interactive web applications. I’m interested in the whole path from understanding an operating problem to building, explaining and improving the tool that solves it.

## Selected work

### Handrail · An interactive partnership proposal

A business proposal presented as a scroll-driven, three-dimensional paper experience. Semantic HTML keeps the terms readable, while the same content supplies the proposal notes and PDF. The repository includes the camera geometry, accessible reading paths and browser regression tests.

[Explore the proposal](https://brentthomas248.github.io/handrail-proposal/) · [Inspect the source](https://github.com/brentthomas248/handrail-proposal)

### Arms Inventory · From invoice to inventory workflow

I founded Arms Inventory and build its product for firearm dealers working with distributor invoices, purchase orders and POS exports. The workflow brings document parsing, matching and human review together around a practical operating task.

[View the product](https://armsinventory.com)

### Dance Floor Bros · A tool for making design decisions

An interactive brand studio with independently selectable color and typography directions. Built to help a business compare options in context and communicate a choice, with a plain-text handoff.

[Try the studio](https://brentthomas248.github.io/dfb-brand/studio.html) · [Inspect the source](https://github.com/brentthomas248/dfb-brand)

### Demand forecasting · From raw data to an evaluated model

An academic forecasting project with Python/PySpark feature engineering, gradient-boosted models and rolling-origin evaluation. Includes reproducible setup, baseline comparisons and documented limitations.

[Explore the project](https://github.com/brentthomas248/shotgun-demand-forecasting)
